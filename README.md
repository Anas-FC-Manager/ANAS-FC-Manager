# تطبيق أنس

مشروع أندرويد لحفظ سجل الحافظة محلياً مع تشفير AES-GCM باستخدام Android Keystore وقفل برمز PIN.

## البناء
يبدأ GitHub Actions تلقائياً عند تحديث الفرع الرئيسي. افتح تبويب **Actions** ثم اختر آخر تشغيل ناجح ونزّل artifact باسم **Anas-Clipboard-debug-apk**.

## ملاحظات
- لا يقرأ التطبيق الحافظة باستمرار في الخلفية؛ أندرويد يقيّد ذلك. افتح التطبيق بعد النسخ أو شارك النص إليه.
- النصوص المخزنة مشفرة محلياً. لا تنسَ رمز PIN.
- ملف APK الناتج من Gradle هو نسخة debug للاختبار، وليس إصداراً منشوراً على متجر.
