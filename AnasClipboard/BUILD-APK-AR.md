# استخراج APK لتطبيق أنس عبر GitHub

1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Anas Clipboard APK** ثم اضغط **Run workflow**.
3. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
4. نزّل `Anas-Clipboard-debug-apk` وافتحه؛ ستجد داخله `app-debug.apk`.
5. انقل APK إلى هاتفك وثبّته بعد السماح بالتثبيت من هذا المصدر عند الطلب.

هذه نسخة Debug للتجربة وليست إصداراً منشوراً على متجر Play. التطبيق لا يلتقط كل النسخ في الخلفية؛ أندرويد يقيّد ذلك.
