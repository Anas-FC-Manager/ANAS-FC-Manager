# تطبيق أنس — Android clipboard saver

مشروع أندرويد أولي باسم «تطبيق أنس» (Kotlin، بدون مكتبات خارجية).

## الوظائف الموجودة
- حفظ النص الحالي من الحافظة عندما يكون التطبيق مفتوحاً.
- التقاط تغييرات الحافظة أثناء وجود التطبيق في الواجهة.
- حفظ النصوص التي تتم مشاركتها إلى التطبيق عبر Android Share.
- سجل محلي حتى 500 نص، مع نسخ وحذف ومسح الكل.

## قيد مهم في Android 10 وما بعده
النظام يقيّد قراءة الحافظة للتطبيقات التي تعمل في الخلفية. لذلك لا يمكن لهذا التطبيق، بصلاحيات عادية، أن يلتقط كل عملية نسخ فور حدوثها أثناء وجود المستخدم داخل Facebook أو أي تطبيق آخر. عندها استخدم «مشاركة» ثم «تطبيق أنس»، أو افتح تطبيق أنس بعد النسخ ليحفظ آخر نص موجود في الحافظة.

## البناء
افتح المجلد في Android Studio حديث، ثم نفّذ Sync Project with Gradle Files، وبعدها Build > Build APK(s).

- minSdk: 23
- targetSdk: 28
- package: com.anas.clipboard

لم يتم تضمين APK في هذه الحزمة؛ يجب تشغيل GitHub Actions لبناء نسخة APK.
